# Трансформер
## Обзор
Трансформер состоит из трёх основных вещей:
- Embedding (векторизация токенов в многомерное пространство)
- Trasnformer block (использует self-attention и собирается в многослойный перцептрон)
- Вероятности, определяющие следующий токен
## Эмбеддинг
Изначальные слова преобразуются в токены. GPT-2 имеет словарный зопас в 50000+ токенов. Каждый токен имеет числовой идентификатор. В этой модели происходит перевод токена в векторное представление. Векторизатор имеет **обучаемые** параметры. Он может обучаться вместе с моделью.
## Positional Encoding
Для того, чтобы дать возможность модели понимать порядок слов в предложениях, мы добавляем информацию о положении. Это делается сложением embedding вектора и вектора positional encoding. $\mathbf{e}\cdot\mathbf{pe},\mathbf{e} \in \mathbb{R}^n,\mathbf{pe} \in \mathbb{R}^n$.
GPT-2 использует обученный positional embedding, хотя современные модели могут использовать `RoPE`, который кодирует позицию вращением определённых векторов.
# Блок трансформера
Transformer block - это основная вычислительная единица в трансформере. Она состоит из двух частей:
- Multi-head self-attention (позволяет токенам делиться информацией)
- MLP (уточняет детали токенов)
Self-attention позволяет определять релевантные токены для каждого входа. Multi-head self-attention распараллеливает процесс, позволяя выделять разные аспекты текста.
## Self-Attention
Механизм самовнимания состоит из $\mathbf{Q}$, $\mathbf{K}$, $\mathbf{V}$ (query, key, value). Он трансформирует позиционированные эмбеддинги в эмбеддинги Q, K и V с помощью обучаемых параметров $\mathbf{W}$ и $\mathbf{b}$.
После создания эмбеддингов Query сравнивается с Keys для оценки релевантности, после чего результат их произведения используется для взвешивания Value эмбеддинга.
Множество голов имеют свои обученные матрицы весов, на основе которых формируются Q, K, V эмбеддинги. Каждая такая голова занимется разным анализом (смысли, грамматика, связи и т.д.).

Итак, умножаем матрицы Q и K, чтобы получить `attention_score` матрицу. Сгладим её, поделив на $\sqrt{d_k}$. На результат наложим специальную маску (***Masked Attention***), которая исключает будущие токены (вехний треугольник равен 0), нижний треугольник и главная диагональ решают, что от чего зависит.

Извлекаем вероятности, применив алгоритм `softmax`. Суммы строк должны давать единицы. Так мы получили фокус на предыдущих токенах.

Результат оценки внимания помножаем на эмбеддинг Value матрицы и получаем Attention output. Результат от каждой головы конкатенируется возвращая размерность позиционированного эмбеддинга на входе.
## Многослойный перцептрон (MLP)
Результаты механизма внимания подаются на многослойный перцептрон для уточнения репрезентации токенов. Линейный слой используется для преобразования эмбеддингов через веса и смещения, а нелинейные слои активации определяют, как сигнал будет проходить дальше. В GPT-2 используется GELU, который сильные сигналы отправляет полностью, а слабые частично.
# Выходной слой и логиты
Последний слой преобразует весь пройденный сигнал в логиты, представляющие собой сырые числа, которые отражают вероятности для каждого токена из словаря. Эти логиты нужно преобразовать в вероятностное представление от нуля до единицы. И тут можно применять разные стратегии по выбору токена, не беря лишь только токен с наивысшей вероятностью.
## Температура
Перед превращением в вероятности логиты масштабируются при помощи температуры. Чем она ниже, тем больше контраст между логитами (большие логиты становятся больше, маленькие меньше), делая результат предсказуемым. Чем выше температура, тем меньше контраст между логитами, сглаживаются разницы, повышая креативность.
## Стратегия сэмплирования
Мы создаём выборку из токенов, применяя жадные алгоритмы. `top k` выбирает `k` самых вероятных токенов, а `top p` создаёт пороговое значение для токенов, набравших `p` баллов. Наконец, применяется softmax для получения вероятностей из обработанных логитов.
